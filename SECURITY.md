# Security policy

This is an experimental radio-control project and has not been tested on a
real G7250. Please do not publish credentials, callsigns, grid locators,
radio recordings, logbooks, or other private data in an issue or pull request.

To report a security problem, open a private security report through the
repository's GitHub Security tab when available. If private reporting is not
available, contact the repository owner before publicly disclosing details.
