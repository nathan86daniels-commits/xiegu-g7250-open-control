# Contributing

Contributions are welcome, especially reports from people who can test the
software safely on real G7250 hardware.

Before opening an issue or pull request:

- State whether the built-in simulator or a real radio was used.
- Include the radio firmware version when reporting hardware behaviour.
- Do not include callsigns, grid locators, credentials, logbook exports,
  recordings, or other private station data.
- Do not test transmit features without appropriate RF safety precautions.

Hardware reports should clearly distinguish observed behaviour from assumed
protocol behaviour.
